# LegendKids Functional Prototype — 22 November 2026

Open `prototype/index.html` in any local browser, no server required.

**Working:** six-step form (child name, age, gender, educational purpose, literary genre, illustration style, favorite details), validation, back navigation, deterministic sample story, five-page preview, simulated no-charge purchase description, responsive layout. Everything runs client-side; no network calls, photos, payment, keys, or storage.

**Not built:** original recovered server graphics and fox mascot; full original Telegram bot; AI literary generation; AI imagery; professional edited stories; proper PDF export; genuine payments; production deployment. It is a functional UX **demo**, not a saleable story or approved product. Illustration is schematic and created for this demo.

Harness: compare with actual legacy Telegram FSM and recovered assets; independently run visual/mobile/accessibility test; use as provisional interface scaffold only. Build and test a real end-to-end no-charge **test-bot** and full product PDF in separate protected staging, and preserve old proven layout wherever better. This prototype must not replace the original bot or be merged blindly.
